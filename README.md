# RETROX - release downloads

This repository holds **release assets only** for RETROX, a game library and downloader
application for Batocera (a Rivet Reworks edition based on RGSX by RetroGameSets).
There is no source code here.

* RETROX finds new versions automatically (Settings > Updates) and installs them only
  after the user approves.
* Every feed is signed (Ed25519) and every package is checked by size and SHA-256.
  A package from here is refused by any RETROX that doesn't trust the signing key.

RETROX contains no games and no BIOS files. Third-party components and their licences are
listed in THIRD_PARTY_NOTICES.txt inside each release package.
